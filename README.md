# AnatomyAR

AR anatomy models (heart, lungs, intestines and skeleton) tracked onto your body in real time through a phone camera. Built at CTRL+HACK+DEL with Amr Radwan and Arianne Ghislaine Rull.

- **Case study:** [chiragdalmia.com/projects/anatomyar](https://www.chiragdalmia.com/projects/anatomyar)
- **Live demo:** https://anatomyar.chiragdalmia.com/
- **Devpost:** https://devpost.com/software/anatomar

Built with React, TypeScript, Vite, Three.js and Geenee body tracking.
